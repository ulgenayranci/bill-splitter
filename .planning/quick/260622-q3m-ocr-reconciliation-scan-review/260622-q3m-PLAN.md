# Quick Task 260622-q3m: OCR reconciliation guardrail + scan-review screen

## Context

Treat the receipt's printed total as the source of truth and make line items reconcile to it. The OCR auto-retry shipped last round (260622-hjb) re-reads once on a mismatch; this adds the human-in-the-loop backstop: when the scan still can't reconcile, show an editable review of the parsed items for the user to confirm/fix before continuing.

Full plan + rationale: `~/.claude/plans/i-have-completed-the-misty-rain.md`.

**Locked decisions:**
1. Review screen appears ONLY when items don't reconcile after the server retry. Clean scans flow straight through.
2. Soft gate — user must see & confirm, but can proceed even if still off ("Confirm & continue").
3. Reconcile against the pre-tax **subtotal** when printed; fall back to the grand total otherwise.

Key fact from exploration: the app tracks NO tax/tip/service, and OCR `subtotalCents` was ambiguous. Hence Task 1 splits subtotal vs grand total. Run on the main tree (no worktree); each task = one atomic commit, pushed to main immediately.

Existing shape rules every script must follow (RESEARCH Pattern 4; verified on real Redis 8.10.2 and Upstash):
- Real Redis decodes JSON null to userdata (not nil) and encodes every empty table as {}; Upstash keeps [] and decodes null to nil. Therefore: guard with `type(x) == 'table'` / `type(x) ~= 'table'`; never `if not x`, never `x or {}` for a field that may be userdata, never compare with cjson.null. Skip non-table elements inside ipairs loops. Never table.remove inside the loop that searches.
- DONE_SCRIPT / TIP_SCRIPT already follow this (copy their people guard verbatim: `if type(session.people) ~= 'table' then return 'invalid_session' end` and `type(p) == 'table' and p.id == personId`).

<objective>
Normalise the cjson []-vs-{} shape drift at the single session fetch boundary (GET /api/session/[sessionId]) and lock v2.0 backward compatibility with a frozen v2.0-shaped session fixture exercised through every path that touches it.

Purpose: Redis Lua's cjson cannot distinguish an empty JSON object from an empty array, so any Lua write (claims, add_person, and now done/tip from plan 12-02) can flip `{}` fields to `[]` (or `[]` to `{}`). v2.1 adds more Lua writes (Phase 13), and Phase 16 UI will key into these maps. Normalising once where the client fetches keeps every consumer correct. The fixture test is the REL-04 regression guard every later phase re-runs.
Output: lib/normalizeSession.ts + tests, GET route wiring, v2-session.json fixture, v2SessionCompat.test.ts.
</objective>
